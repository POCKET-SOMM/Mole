# Mole team 1.54.0-team.1-rc.1 — release draft

This independent POCKET-SOMM fork packages a narrower set of local maintenance
commands from Mole 1.54.0 by Tw93 and contributors. It is a terminal application.

- Automatic update downloads are disabled. Runtime helpers are bundled and never
  downloaded or built on a teammate's machine. Operation history stays local.
- Cleanup presents only the two supported compiler-cache families, requires exact
  selection and typed confirmation, and repeats ownership and identity checks.
- Browser state and app interiors, downloaded dependencies, models and active
  project state remain excluded from automatic maintenance. Homebrew cask hooks
  and package autoremove are unavailable in the supported uninstall flow.
- Storage inventory and duplicate-content inspection are read-only additions.
  Deliberate app uninstall and analyzer Trash actions retain their own safeguards.
- Portable arm64 and amd64 archives include licenses, checksums and build metadata;
  the matching source archive includes vendored dependencies. Updates and folder
  removal are manual. No global CLI alias or background service is installed.

Initial support target: macOS 14 or newer. Built with Go 1.27.1. The exact source
identity and compiler are recorded in `BUILD.json` and `SOURCE_MANIFEST.json`.

This is a candidate, not a signed or notarized release. Native integration on
disposable Macs, review of hosted CI on the final source commit, and the signing
decision remain publication gates. See the accompanying verification report for
actual passed, failed and skipped checks; a cross-build is not an Intel runtime test.

The test-isolation incident involving Chrome is documented in
`docs/TEST_ISOLATION_INCIDENT.md`. The runner now enforces a filesystem sandbox;
native checks unsupported by that boundary must run on disposable Macs.
