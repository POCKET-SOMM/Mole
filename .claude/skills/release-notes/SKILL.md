# Fork release notes

Draft only by default. No fork release workflow or distribution channel exists. Read `.claude/skills/release-flow/SKILL.md` before assessing publication.

Describe the actual change in behavior, compatibility, verification and material limits. Verify commands against the candidate source and link only to the correct fork's changes. Use the user's requested language. Preserve upstream attribution without presenting upstream maintainers, packages or paid products as this fork's own.

Do not run upstream release-edit commands, submit package changes, post reactions, thank users publicly or send account messages as part of drafting. The inherited reaction helper has been removed. Publish only to a concretely identified fork destination when requested and after its artifact and verification plan is ready.
